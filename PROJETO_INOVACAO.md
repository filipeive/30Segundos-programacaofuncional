# Projeto de Inovação Tecnológica: Gamificação no Ensino Superior
## Sistema: 30 Segundos - Functional Programming Edition

### 1. Resumo do Projeto
O projeto **30 Segundos (PF Edition)** é uma ferramenta pedagógica gamificada desenvolvida para dinamizar o processo de ensino-aprendizagem da unidade curricular de **Programação Funcional**. O sistema desafia os estudantes a explicarem e consolidarem conceitos complexos (como Monads, Recursão e Currying) sob pressão de tempo, promovendo a agilidade mental e a colaboração em equipa.

### 2. Objetivos
- **Consolidação de Conceitos**: Reforçar a terminologia técnica do plano analítico de forma lúdica.
- **Desenvolvimento de Soft Skills**: Estimular a comunicação clara, síntese de ideias e trabalho em equipa.
- **Inovação na Sala de Aula**: Substituir métodos tradicionais de revisão por uma experiência interativa e competitiva.

### 3. Justificação Pedagógica
A aprendizagem de linguagens funcionais (como Haskell) apresenta uma curva de aprendizagem acentuada devido à sua natureza abstrata. A gamificação, através deste sistema, reduz a ansiedade dos estudantes e aumenta o engajamento, permitindo que a revisão da matéria seja vista como um desafio e não como uma tarefa exaustiva.

### 4. Tecnologia Utilizada
- **Lógica**: JavaScript (Vanila) para gestão de estados, timers e aleatoriedade.
- **Interface**: HTML5 Semântico e CSS3 Moderno (Gradients & Flexbox).
- **Design**: Iconografia vetorial (Lucide Icons) e tipografia focada em legibilidade (Outfit/Inter).

### 5. Potencial de Escalabilidade
Este sistema foi desenhado de forma modular. A base de dados de palavras (`WORDS_DATABASE`) pode ser facilmente adaptada para qualquer outra cadeira (ex: Redes, Bases de Dados, Engenharia de Software), tornando-se uma ferramenta transversal para a universidade.
